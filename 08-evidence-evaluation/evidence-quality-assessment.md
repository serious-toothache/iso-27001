## 2. Meta-controls: was the evidence generator itself working all period?

| Question | Answer | Effect on reliance |
|---|---|---|
| Was logging on for the entire period? | CloudTrail trail logging ✅ throughout (no `StopLogging` events). **AWS Config recorder ❌ stopped 14–19 Aug** | Config-based conclusions exclude those 6 days. That gap is itself a finding (GAP-18) |
| Was retention sufficient? | CloudTrail in S3, no expiry ✅. **GitHub Actions logs 90 days ❌** | Build-log evidence missing for 1–24 Jul (GAP-17) |
| Were controls continuously enabled? | **Branch protection weakened for 3 h 33 min on 12 Aug ❌** (from the audit log) | PRs merged in that window tested individually (#241) |
| Is the log tamper-evident? | **No.** Log file validation off, no Object Lock (GAP-06) | CloudTrail stays tier 2. Every CloudTrail-based finding is corroborated by a second source |

## 3. Anti-patterns refused

- **"Evidence provided by management"** doesn't appear in any workpaper. Each one names the file, the system it came from, and its hash.
- **No screenshots** were requested or used. Where only a description existed (the IR plan), it was treated as a description.
- **"No exceptions noted"** is never written without saying how the test would have surfaced one.
